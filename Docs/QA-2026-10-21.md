# QA pass — 2026-10-21

Scope: scripted Studio play sessions (idle, combat, floor advance on Hard, death flow on Easy and Nightmare), the static gates (stylua, selene, luau-lsp both places, verify_places), and four read-only code audits (UI and mobile, VFX and client perf, mobs and combat, run flow and services). Mobile was audited against an 812×375 landscape phone from code only; nothing ran on a device. Nothing was fixed. Items marked **verified** were reproduced in Studio; the rest come from reading the code.

## P0 — exploit, blocking, or data loss

1. **Coins and Ore may be lost on disconnect (introduced today).** `RunEscrowService.lua` banks on raw `Players.PlayerRemoving`, but DataService and CurrencyService clean up on `PlayerEventService.OnPlayerRemoved`, which connects earlier; if the currency registry is already gone the bank warns and does nothing. The "no profile" guard never trips because `GetProfileData` returns `{}`. Trigger: disconnect mid-run carrying coins or ore. Fix is to hook the currency bank into the same early edge, before the profile is released.
2. **Extraction grants the clear-bonus EXP more than once.** `RunFlowService.lua:452-509`, `LifeService.lua:402-433`, `ExpRewardService.lua:82`. `OnPlayerExtracted` fires on every portal prompt; `run.exited` is only set after the teleport returns, and never if it fails. Spam the prompt during the sweep, or after a Studio teleport failure.
3. **Drop pickups have no distance check.** `Components/Drop.lua:103-124`, `GearDrop.lua` collect handler, `Relic.lua:78`. The server checks ownership and death only. An exploiter can vacuum every gem/orb on the floor and take a teammate's death spill from across the map.
4. **Native deaths bypass the life system (verified).** Setting the Humanoid's health to 0 (what a void fall or any non-DamageService kill does) respawns the player with the escrow intact, no life lost, no downed state. LifeService only intercepts `DamageService.PlayerTakeDamage`; `Humanoid.Died` and `FallenPartsDestroyHeight` are not handled anywhere.

## P1 — visible bugs and large costs

### Run flow and death
5. **Errors on every floor advance with live mobs (verified).** `MobBase.lua:1388` throws "No RagdollTrigger BoolValue" from the AI tick after the model was destroyed by teardown; three errors per advance with three mobs alive.
6. **Floor teardown leaves loot behind.** `RunFlowService.lua:229-265` never clears `IgnoreInstances.Drops`, `GearDrops` or relic drops; `GearDropService._preservedEntries` (line 1059) leaks. Gear has no expiry and the next floor generates at the same origin.
7. **Downed players can be sealed on the wrong side of a gate.** `GateService.lua:662-748` skips ineligible players, leaves them in `DesyncedPlayers`, and the gate closes; mobs then ignore them.
8. **Downed or dead players are left in the void on a floor swap.** `RunFlowService.lua:323-333`, `LifeService.lua:795-800`: released above the torn-down floor; revive only teleports fully-dead players with a cursor above 0.
9. **A paid revive after a wipe returns an empty run.** `LifeService.lua:760-763`, `RunEscrowService.lua:662-666`: the escrow is already discarded and GameOver already sent when the revive cancels the teleport.
10. **A cleared run still loses dead players' gear.** `RunEscrowService.lua:658,707`, `LifeService.lua:368-390`: `TeleportAllToLobby` never fires `OnPlayerLeavingToLobby`, and dead players cannot use the portal, so the leave path spills the gear.
11. **Teleport failures have no recovery.** `LifeService.lua:384-389, 425-432`: a failed lobby teleport strands the party; `TeleportInitFailed` is unhandled.
12. **Run difficulty trusts client TeleportData.** `RunFlowService.lua:554-622`: `Difficulty` and `partyLeaderUserId` are client-supplied; the unlock clamp is skipped if the leader's profile takes over 15 s, and the level gate is skipped on an unloaded profile.
13. **A failed next-floor generation softlocks the run.** `RunFlowService.lua:300-317`: the index is already bumped and the old floor destroyed. Separately `DungeonGenerator.lua:696, 839` can `break` and ship a floor with no Boss.
14. **Ascension growth never reaches gear drops.** `GearDropService.lua:174-221` reads static `DungeonData` tiers, not `DifficultyData.Resolve`, so Ascension 10 drops what Ascension 1 drops.
15. **Floor advance hitch (verified).** Teardown plus generation costs a 180 ms server frame and six frames over 33 ms per advance. It hides behind the black fade today.

### Mobs and combat
16. **Boss phase-2 slam freezes for twice its length.** `MobData.lua:559-574, 691-706` return the windup that `MobService:SpawnHitbox` already waited; `MobBase.lua:1344` waits it again. Hard boss under 33% stands frozen ~2.6 s.
17. **Scripted mass-kills pay EXP and gear.** `MobSpawnService.lua:879-882` sets health to 0, which runs the full death path for any mob a player ever touched. Fires on miniboss/boss death, every boss phase cutscene, and a failed Coffin event (paying out on the Defeat screen). Only gems are room-gated.
18. **Ranged mobs retarget mid-windup.** `MobBase.lua:1393` vs `1397`, `1321-1326`: the fireball is registered to whoever is nearest after the windup, so the player it hits takes no damage.
19. **Ranged damage is client-reported.** `MobService.lua:643-716`: damage only lands when the targeted client fires `MobProjectileHit`; blocking the remote gives immunity. `player.Character :: Model` at 709 errors on a missing character.
20. **No rewards when the killer has no character.** `MobBase.lua:1456-1457`: assists, gear, gems and procs only run in the killer-present branch (a leaver's DoT, or a respawn in flight).
21. **An error inside an attack sticks the mob forever.** `MobBase.lua:1211-1264` has no pcall; a throw leaves Attacking state, SuperArmor on, WalkSpeed 0.
22. **Pathfinding cost.** `MobBase.lua:989-991`: `Plastic = math.huge` fails `ComputeAsync` on any Plastic floor, then every blocked mob re-paths each second with no cap; `WaypointSpacing = 1` yields a waypoint per stud.

### Client, VFX, performance
23. **Preload warm-up re-runs on every spawn, twice on first load.** `PreloadController.lua:350-391` listens to `OnCharacterLoaded`; each run re-clones ~4,700 VFX instances and plays every spell. `SusanooArmor.lua:43-53` roots the player for 2.25 s during it.
24. **Projectile speed depends on frame rate.** `WizardFireball.lua:44,230,327`, `FireBlast.lua:58-60`, `HollowPurple.lua:159` step by `speed*0.01` per frame; at 30 fps a fireball flies at 30% speed and half the range, desynced from the server.
25. **Fireball thread can error while the local player is dead.** `WizardFireball.lua:165,268`: `localCharacter` captured once, `IsDescendantOf(nil)` throws, projectile freezes with emitters on.
26. **Bullet VFX cloned per shot, no pooling.** `ProjectileCastController/init.lua:313-336`, `weldProjectileHole.lua:20`: ~80 clones/s with four players firing, ~300 live VFX models per client.
27. **Server projectiles rebuild RaycastParams every frame.** `ProjectileCastService/init.lua:321`: O(projectiles × ignore list) per Heartbeat.
28. **Damage numbers have no cap or pooling.** `DamageIndicatorController.lua:324-460`, `playHitBurst.luau:47-80`: a Part, a BillboardGui and 6-8 tweens per hit, plus StatusFX clones per proc.
29. **Other players' orbiting relics can stay invisible.** `RelicRenderController.lua:214-218` parents the orbit only if the owner's root exists at sync time, never retried.
30. **Relic machine jitters on landing.** `RelicMachine.lua:134-144, 191-193`: position tweens fight a `ScaleTo` driven every change of the elastic value (~120 calls).
31. **Combat frame spike (verified).** One 68 ms server frame during a four-mob chase; the kill burst itself stayed under 25 ms.

### UI
32. **Inventory detail fade targets the wrong panel.** `Inventory Container.luau:960, 1068`: two panels share one ref; which one fades depends on table order.
33. **Selection is not cleared when the item leaves the profile.** Inventory `Container.luau:298-306`, Blacksmith `Container.luau:525-533`: blank detail pane with no button until a tab click.
34. **Opening Bag or Forge hides the toggle that opened it.** `Inventory init.luau:105`, `TopBar init.luau:349-360`; on mobile the only exit is a ~19 px X.
35. **Bag, Forge and run inventory stack on top of each other.** `UserInputController.lua:182-189`: no mutual exclusion.
36. **Blacksmith Cost row on phones.** The flow labels use `AutomaticSize.X` plus `TextScaled` with no `TextSize`; at ~14 px row height the contents need ~200 px in a 136 px row and the success pill leaves the panel. Needs a device check.
37. **Blacksmith hangs if the upgrade RPC never returns.** `Container.luau:783-817`: "rolling" is permanent; pcall does not catch a hang.
38. **Relic tray double-drop/sell.** `Relic Container.lua:646-659, 691-704`: the description keeps the old relic ~0.5 s after deselect; a double-tap drops or sells both copies.
39. **Relic tray toggle bypasses RequestOpen.** `Relic Container.lua:869-873`: opens during cutscenes, death, or over the run inventory.
40. **Lives UI never shows.** `Lives Container.lua:188` hardcodes `Visible = false`; also fixed pixel sizes and a placeholder-art TODO. Confirm whether hiding it was intentional.
41. **Mobile action buttons.** `MobileActionButtonInterface/init.lua:300-333` computes the cooldown tint but never applies it; 264-275 re-shows Roll/Swap after a cinematic while spectating.
42. **Hover states stick on touch.** `CategoryFrame.luau:219-225`, `InventoryItemFrame.luau:305-311`, `RunItemFrame.luau:372-387`, `DialogueBillboard.luau:749`: MouseEnter fires on tap, MouseLeave often never, so tiles stay enlarged and every tap plays hover plus click sounds.
43. **Possible boss-bar crash.** `EncounterBar Container.lua:472` reads `MobData[name].subtitle` with no nil check; a non-MobData encounter name would kill the bar for the session.
